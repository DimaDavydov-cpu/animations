How to use

        

      

      

        
Card
Draw a rectangle or square with Pencil. One stroke or several, then pause. Every card is a stack: what you add inside flows vertically or horizontally with a Penta gap and padding.

        
Card properties
In Select mode (or with Finger mode off) tap a card. The panel shows direction, gap, padding, alignment, size (Fixed, Fill, Hug), fill, border, radius and elevation.

        
Nesting
Draw a rectangle inside a card to nest one. Draw a rectangle around existing items to wrap them in a new stack.

        
Text
Draw a straight horizontal line with Pencil (at least two grid columns wide on the canvas) or tap where the text goes, then handwrite inside the box. iPadOS Scribble converts it. Pick H1, H2, H3, body… in the toolbar.

        
Edit text
Write over existing text with Pencil. Scratch out words to delete them (Scribble gestures).

        
Background
In Select mode (or with Finger mode off) tap the empty artboard to choose its color. Use the hex field for exact values.

        
Select / move
In Select mode a finger tap selects; drag a selected item to reorder it in its stack, into another card, or out onto the artboard. Corner handles resize. Two fingers scroll the page.

        
Canvas width
Adaptive (default) uses the full available width. Drag the handle on the canvas's right edge to resize it, pick iPad or Mobile, or tap the width next to the scale (for example 1194 px) to type an exact width. Height is automatic.
Scale
Tap the percentage in the top bar to switch between 100%, 75% and 50%. Touch never changes the scale: two fingers only pan.
Grid snapping
Card edges snap to the layout grid's columns and margins when within 20 px. A red guide shows the line they snapped to.

        
Finger mode
On by default: in Draw mode your finger draws like Pencil, and two fingers scroll. Turn it off in the ••• menu to select and scroll with one finger.
Without Pencil
Mouse draws in Draw mode. Use Select mode (V) to select, move and pick the background color.
